# 规则与风险策略

规则用于识别重复连接、跨端口探测、认证失败、协议异常、客户端指纹和协议字段。规则命中产生 `RuleMatched` 事件，并记录规则 ID、版本、命中摘要、风险增量和动作。

规则发布流程为：草稿 → 观察 → 生效 → 回滚。正在生效的规则不直接覆盖；临时放行必须有范围、原因、操作者和到期时间。

风险状态与网络阻断分开：一期默认只更新 `ThreatIpProfile`，`Blocked` 代表策略状态，不直接修改宿主防火墙。真实阻断、威胁情报联动和自动化处置需要单独的权限、审计、过期和回滚设计。

当前只有代码中的最小判定阈值示例，尚未建立可发布规则集。

认证相关规则默认把每次认证尝试标记为失败并增加风险分；无论输入账号或凭据如何变化，都不产生成功登录状态。攻击者提交的原始密码和认证材料必须进入加密证据仓库，并通过 `credentialArtifactId` 与事件关联。若未来需要虚拟账号诱捕，必须单独设计并经过安全评审。
