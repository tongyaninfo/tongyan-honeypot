# 传感器与监听运行时

传感器运行时负责接收不可信连接并转换为受控事件。端口监听不放在协议适配器中，由统一 `ListenerHost` 管理；同一服务实例可以绑定多个 `ListenerBinding`，每个绑定独立记录端口、状态、连接数和错误数。

## 处理顺序

1. 监听器完成 TCP accept；
2. 生成 `ConnectionAccepted` 并写入可靠队列/WAL；
3. 更新来源 IP 的威胁档案；
4. 创建协议适配器会话；
5. 追加 banner、握手、认证、规则和关闭事件。

客户端不发送数据即断开，也必须保留连接事件。SYN 半连接、被防火墙丢弃的探测需要独立的抓包/eBPF/防火墙日志传感器，不由普通应用 socket 记录冒充。

## 运行限制

每个监听器和会话必须限制最大连接数、每 IP 速率、握手超时、空闲超时、最大帧、单会话字节数和总会话时长。管理面与诱捕端口分离，适配器默认禁止主动外联、宿主命令、文件读取和真实服务连接。

当前仓库尚未实现真实传感器；管理 API 的事件预览接口不等同于网络蜜罐监听器。
