# 版本与发布

本目录记录版本规则、发布清单、数据库升级和制品约定。当前源码为 0.1.0 工程初始化版本，尚未封版。

## 版本规则

- 根 [VERSION](../../VERSION) 是产品版本唯一来源，当前为 0.1.0。
- [CHANGELOG.md](../../CHANGELOG.md) 面向使用者；开发依据、验证边界与内部验收记录不随公开仓库发布。
- 后端、前端和发布包版本从根版本投影，不各自维护另一套版本。
- 数据库迁移编号独立记录，不能重写历史迁移。

## 数据库启动和升级

- 服务启动时在数据目录自动创建 SQLite，并执行连续的正向、非破坏性迁移。
- 迁移前生成备份；未知、更高或不连续的数据库版本应停止并报告，不能继续启动。
- 需要删除数据、清空表或不可逆重建时，不由普通启动自动执行。
- 迁移失败保留原数据库和备份，不覆盖或删除。

## 制品组成

```text
backend/       Honeypot.Api 自包含发布
frontend/dist  管理台静态产物，复制到 Api 的 webroot 或由反向代理托管
docs/          产品文档
scripts/       协议与运行验证脚本
```

管理面与诱捕端口应使用不同网络路径逐层放行，发布前确认监听范围、数据目录权限与备份策略。

## 发布前检查

- 版本、CHANGELOG 和发布记录一致；
- 文档链接与状态标注检查通过；
- `dotnet build`、`dotnet test`、`npm run lint`、`npm test`、`npm run build` 实际运行；
- SQLite 自动迁移、备份与回滚步骤实际验证；
- 监听、认证失败记录、证据留存、报告与通知、Syslog 转发按改动范围验证；
- 制品无真实凭据、私钥、主机信息或观测数据；
- 部署与监听端口验收只在获准的隔离环境执行。

当前没有版本发布记录或可部署制品。
