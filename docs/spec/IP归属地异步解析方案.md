# IP 归属地异步解析方案

## 已确认需求

2026-11-10 接入通研 IP 适配器：系统管理提供 IP 数据库配置；所有来源 IP 保留第一行地址，第二行异步补齐归属地。页面注明“通研IP适配器”和来源 `ip.tongyaninfo.com`。

配置包含解析开关、HTTP/HTTPS、主机、端口、数据库单选和解析超时。数据库为 `CZ88`、`ip2location`、`ip2region`、`dbip`、`ipinfo`、`geolite2`；默认关闭解析，预置 `HTTPS / ip.tongyaninfo.com / 443 / CZ88 / 2 秒`。

## 边界与数据流

业务事件、威胁查询、认证证据接口保持原有处理链。统一来源 IP 组件先显示原地址，再合并请求独立批量解析接口。该接口仅做本地分类、内存缓存查询和非阻塞入队，立即返回已有结果或待解析状态，外部 HTTP 只能由后台工作任务执行。

后台采用有界队列、固定并发、在途去重和限量缓存；超时、错误、队列满均降级为显示状态，不阻塞采集或列表接口。超时覆盖连接、响应头和响应体读取；响应大小有上限，不自动跟随上游重定向。配置变更取消旧任务并失效旧缓存，关闭开关后停止新增外部查询。

私网、回环、链路本地、保留地址在本机识别，CIDR 标为网段，不发送给供应方。外部解析仅发送待展示的公网 IP 和所选数据库，不携带蜜罐凭据、事件正文或用户会话。前端批量轮询只在组件仍挂载时运行，结果缓存有容量和有效期限制。

## 配置与权限

沿用现有 `Honeypot:DataDirectory` 配置目录，以独立 `ip-location-settings.json` 原子写入保存，不新增数据库表或迁移。配置读取失败时采取关闭解析的策略。

读取和修改完整设置仅限管理员；已登录用户可以使用批量解析接口。协议、主机、端口、数据库、超时以及批量大小均在服务器校验，前端按钮和路由限制不能代替后端鉴权。

## 上游合同

默认请求 `/?ip={ip}&db={database}&format=json`，用户指定的 `/search/{ip}?db={database}&format=json` 与根路径共用上游查询实现。响应从 `data.sources` 按所选数据库匹配来源，并核对响应 IP。

展示字段取来源 `fields.country / region / city / isp`；`region` 映射省份/地区。当前上游没有独立区县字段，因此区县保留空值。CZ88 可仅提供地区原文与运营商描述；某些数据库即使返回成功也没有位置字段，应显示“暂无归属地”，不能推测国家、省市或区县。

## 验证与回滚

使用隔离 HTTP 替身覆盖默认关闭、设置校验、IP 分类、并发限制、队列满、去重、缓存失效、超时、空结果和上游异常；验证管理员与普通用户权限及统一响应合同。前端检查配置表单、异步补齐、合批及相关页面回归，并执行构建。

测试地址仅做少量只读查询，不修改上游服务。测试地址不写入代码默认值和仓库示例。禁用解析即可停止新查询并取消旧配置任务；回退应用版本时，独立配置文件不会改变已有业务数据库或数据合同。

本方案不代表已部署或完成容量、持续负载和现场验收；实际执行的命令与结果在发布说明中登记。
